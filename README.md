# Sainath Punchbhai — Robotics Portfolio

A responsive, animated static portfolio website designed for GitHub Pages.

## Files
- `index.html` — page structure and content
- `styles.css` — visual design, responsive layout and animations
- `script.js` — mobile navigation, project detail toggles, scroll progress and reveal effects
- `assets/favicon.svg` — browser icon

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email address.
2. Replace the LinkedIn and GitHub placeholder links with your actual profile URLs.
3. Review project descriptions and only claim features/results you can substantiate.
4. Add your own project photos, CAD renders, demo videos and resume.
5. Preview `index.html` in a browser and check desktop and mobile layouts.

## Publish with GitHub Pages
1. Create a public repository named `robotics-portfolio` (or your chosen name).
2. Upload the **contents** of this folder to the repository root, including `index.html`.
3. Open repository Settings → Pages.
4. Under Build and deployment, select `Deploy from a branch`.
5. Choose branch `main`, folder `/(root)`, and Save.
6. After deployment, open the URL shown in the Pages section.

For a project repository, the URL will look like `https://YOUR-USERNAME.github.io/robotics-portfolio/`.

## Notes
- This site uses plain HTML, CSS and JavaScript. It does not require a build step or npm.
- The Google Fonts import is optional; if unavailable, system fonts are used.
- The robotic-arm and project artwork in this starter are original schematic-style SVG/CSS illustrations, not photos of real hardware. Replace them with authentic project media for the final portfolio.
- No analytics, forms, trackers or external runtime libraries are included.
